Health Dashboard

Health Dashboard is a personal-use application for reviewing health, body-composition, nutrition, recovery, endurance, and strength-training trends in one place.

The dashboard combines direct Withings measurements with Google Health/Cronometer data and Hevy workout data. It is intended for the account owner's own use and is not offered as a public medical or health service.

Privacy Policy

This site provides public information about the application for OAuth consent and privacy purposes. The interactive dashboard itself is hosted separately.
